# 🌐 Internet Technologies Exercise 03

A collection of **HTML and CSS layout exercises** developed for Internet Technologies coursework. This project demonstrates the use of **CSS positioning techniques and Grid layout system** to build structured web page designs without frameworks or JavaScript.

---

## 📌 Project Overview

This project contains multiple UI layout design exercises implemented using only HTML and CSS. It focuses on mastering CSS positioning concepts such as **relative, absolute, fixed, sticky positioning**, along with **CSS Grid Layout**.

The designs are based on tutorial and lecture reference videos and emphasize layout accuracy and structure preservation.

---

## 🎯 Objectives

* Understand CSS Positioning (relative, absolute, fixed, sticky)
* Practice CSS Box Model concepts
* Learn CSS Grid Layout system
* Build structured and fixed UI layouts
* Improve front-end layout design skills

---

## ✨ Exercises / Cases Implemented

### 🔹 Case 1: Full Screen Absolute & Relative Position Layout

* Uses only relative and absolute positioning
* Full screen design layout
* Fixed structure that does not change on resize
* No images allowed

---

### 🔹 Case 2: Sidebar Layout Design

* Structured layout using HTML elements
* Combination of relative and absolute positioning + box model
* Sidebar automatically adjusts height based on content
* Layout remains stable when content is added
* Uses Google Fonts and Font Awesome for styling

---

### 🔹 Case 3: Fixed Position Layout Design

* Uses fixed positioning technique
* Two main bordered sections remain fixed at center of viewport
* Content flows inside the layout
* Full screen design implementation

---

### 🔹 Case 4: Sticky Position Layout Design

* Uses sticky positioning concept
* Elements stay fixed while scrolling when required
* Full screen structured layout
* Interactive scrolling behavior

---

### 🔹 Case 5: CSS Grid Layout Design

* Layout built using CSS Grid system
* Structured content alignment
* Responsive grid-based design structure

---

### 🔹 Case 6: Advanced Grid Layout Design

* Extended CSS Grid layout implementation
* Complex structured UI design
* Organized multi-section layout using grid

---
